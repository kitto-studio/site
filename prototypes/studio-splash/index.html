Заставка Kitto перед Memory Missing

Каждый вариант собран из материалов самой игры: размытая палата, бирюзовая линза, запотевшие плитки, полароид. Сначала заставка студии, потом плавный переход в настоящий сплеш игры.

В конце показан текущий сплеш игры, снятый с её визуального теста. Логотип в светлой версии, буквы двигаются по отдельности.
